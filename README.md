# ConsultoresGyc_Web
# Proyecto de desarrollo web para consultores de servicios energéticos

La plataforma ConsultoresGyc_Web se divide en cuatro módulos diseñados para aumentar la eficiencia en la búsqueda de clientes y reducir el trabajo administrativo de su equipo.

## Módulo 1: Portal Web Corporativo
El portal web corporativo es el punto de partida de la plataforma. Se caracteriza por:
* Diseño moderno adaptado a dispositivos móviles
* Página de inicio con información destacada
* Galería de imágenes conectada a Instagram y TikTok
* Catálogo de servicios y kits fotovoltaicos

## Módulo 2: Cotizador Automático
El sistema de cotizador automático permite a los clientes ingresar sus datos y obtener un presupuesto referencial en tiempo real. Incluye:
* Ingreso de datos: número de medidores y tipo de inmueble
* Cálculo de presupuesto y generación de ticket de atención
* Acceso a información del cliente y estado del procesamiento

## Módulo 3: Panel de Administración
El panel de administración ofrece acceso privado para que el equipo edite y ajuste información sin requerir conocimientos técnicos. Incluye:
* Edición de textos y fotos
* Ajuste de precios y tarifas
* Acceso a información del cliente y estado del procesamiento
* Almacenamiento seguro de documentos (PDF, planos)

## Módulo 4: CRM Interno
El CRM interno es el tablero privado donde el equipo comercial gestiona las solicitudes y reciben notificaciones automáticas. Incluye:
* Solicitudes ordenadas por estado (Nueva, Cotizada, Aceptada)
* Avisos automáticos por WhatsApp y correo electrónico
* Almacenamiento seguro de documentos (PDF, planos)

La plataforma ConsultoresGyc_Web está diseñada para aumentar la eficiencia y reducir el trabajo administrativo de su equipo, mientras que ofrece una experiencia de usuario atractiva y fácil de usar para sus clientes.
